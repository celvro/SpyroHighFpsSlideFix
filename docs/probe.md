# SpyroFpsProbe (dev mod)

## Quicksave (V / B / L / N, added 2026-09-17)

Testing aid, in the probe only. One quicksave slot, not one per level. **V** saves Spyro's spot (level, position, facing, control rotation) to `spots.txt` in the deployed probe folder, which survives restarts and `-ModsOnly` redeploys. **B** goes to it, travelling to its level first if Spyro is elsewhere. **L** reloads the current level's gameplay sublevels, teleporting to the spot afterwards only if the spot belongs to that level. **N** dumps the GlobalTransporter (see below). Velocity and ability state aren't saved, so save while standing. Keys are handled in `sample()`, which skips paused frames. Free keys only: the game binds every number key, W/A/S/D/E/F/P/Q/X/Z, LeftControl and the arrows (`DefaultInput.ini`), F11 toggles fullscreen and UE4SS uses Ctrl+R.

- Teleport: `K2_TeleportTo`, velocity zeroed, `SetControlRotation`, then `FollowCamera:ResetBehind(true)` (it takes one argument; without a snap the camera flies in). `FollowCameraComponent` also has `Reset`, `SetCameraPitchYaw`, `CenterCameraFromSpec` and `PauseUpdate`.
- **Level streaming (verified 2026-09-17):** every level streams into one shared persistent level, `GlobalPersistentLevel`, as runtime `LevelStreamingKismet` instances, placed by `LevelTransform` (LS104 at (−300000, −300000, 0), LS102 at (0, −300000, 0); the transporter has `LevelOffset` 300000 and `BaseLevelPosition` (−300000, −300000, 0)). Their `PackageName`/`PackageNameToLoad` can be empty, so read the package from `LoadedLevel:GetFullName()`. Sublevels are `LS###_{design,Enemy,Loot,Cinematics,Art01..03,ART_MASTER,Lighting,Fx,SFX,Music,Voice,Transport}`. Entries for levels visited earlier stay in `World.StreamingLevels` unloaded.
  - **Don't use `RestartLevel`** (console): it drops to the title screen.
  - The level Spyro is in is the one whose `LevelTransform` is nearest him. Picking "the first visible LS### sublevel" is wrong: a homeworld keeps neighbouring levels' `LS###_Transport` sublevels loaded and visible, which made the quicksave teleport into another level's coordinates (void, no geometry, wrong music).
- **L reload:** clears `bShouldBeLoaded`/`bShouldBeVisible` on the level's `design`, `Enemy`, `Loot` and `Cinematics` sublevels (re-clearing each frame in case the game's streaming re-enables them), waits for `IsLevelLoaded` false, sets them again, waits for `IsLevelVisible`, then teleports to the spot. Spyro is held in Flying with zero velocity because `LS###_design` holds the floor. Takes 1.0–1.3 s, resets enemies and gems, and leaves the transforms unchanged (checked before and after). Progress the game keeps outside those sublevels is not reset.
- **B across levels:** `GlobalTransporter_C` (instance in `GlobalPersistentLevel`, Blueprint on native `TransportManager`) has the game's own load-a-save event `StartAtLevelCheckpoint(Start Level: DataTableRowHandle, isRestart: bool, transitionType: byte EFalconLoadScreen, checkpoint: String)`. It reads the row (`LevelMapPath` + the `LLxxx` sublevel-name table), builds a `LevelStreamingRecord` with `UnloadCurrentLevels`, and calls native `StartAtLevel`, so lighting, music and game state follow. The probe calls it with the table `/GameplayCommon/LevelMechanics/LevelStreaming/StreamingData/LevelStreams/Spyro1_StreamData`, whose 101 rows are named exactly like the level keys (`LS101`–`LS337`, all three games), then waits for `currentLevel` to match and Spyro to be walking before teleporting.
  - The other Blueprint entry is `QueueStream(LevelStreamingRecord, TransportType, RecordType)` → `ConvertStreamData` → native latent `QueueTransport`; the record's fields are mangled (`Load_9_…`, `UnloadCurrentLevels_20_…`), so `StartAtLevelCheckpoint` is the easier call.
- Lua trap that cost a test round: `local a, b = x and x:match(...)` truncates to one value, so `b` is always nil.
- `ue4ss/DevMods/SpyroFpsProbe` (deploy with `Install-UE4SS.ps1 -ModsOnly -Probe`): F5/F6/F7/F8 set `t.MaxFPS` to 30/60/120/0. On load it restores `MaxSimulationTimeStep` to 0.05 if an old build changed it. It prints a `seg` summary per airborne segment, a `drift` line for grounded sliding without input, a `rise` line for every zero-gravity rise (kind ground/water/glide-hover/air, time at launch speed, apex from the launch frame), and charge lines. Those are `charge` (per charge), `turn` (grounded full-lock steer ≥ 0.5 s: yaw rates of Spyro/velocity/camera, radius, accel angle, slip, camera lag), and `camlock` (camera closing a ≥ 10° yaw offset after charge start or turn release: t50/t90 and the equivalent exponential speeds k50/k90, to compare against m_ctrInterp 3.5). Charge detection calls `IGetIsCharging` and falls back to MaxWalkSpeed ≥ 450, and optional calls that fail log `... unavailable` once. The `charge` line also has `startSpeed`, `t400` (from the last untagged frame to 400 speed, for starts below 150), `mouseDist` (raw mouse X), `yawPerMouse`, and `dustSpawns`/`dustRate`/`dustDilationMax` (charge dust effect respawns). CSV `mouse_raw` comes from the probe's own hook on `InputAxis_RightStick_X`; `stick_rx` is the stored value, which the mouse fix replaces. `camdump_<time>_<idle|charge|manual>.txt` holds every reflected `FollowCameraComponent` property (recursing into structs and arrays). It is written once while idle, once ≥ 0.75 s into a charge after the camera transition, and on F9. After the charge dump, `camdump diff` log lines list the values that changed. Per-frame CSV goes to `ue4ss\Mods\SpyroFpsProbe\trace_*.csv` in the game dir. `thief` lines (once a second per thief that is chasing or moving) give speed from position and from velocity, MaxWalkSpeed (average and range), % of time at MaxWalkSpeed, `accelObserved` vs MaxAcceleration, distance to Spyro vs CurrentDesiredDistance, DesiredSpeed, ChaseTime, the most common enemy state, and predicted laughs. Per-frame rows go to `thieves_*.csv`. `flame` lines (one per flame breath, from `NotifyOnNewObject` on `ParticleSystemComponent` plus a `FindAllOf` scan at startup, on pawn change and on F10) give the flame particle component's bounds via `KismetSystemLibrary:GetComponentBounds` and its `InstanceParameters`; per-frame rows go to `flames_*.csv`. Thief (`ChaseSpeedManager_C`/`_S3_C`) and dragon lookups use `FindAllOf`, which only runs for 15 lookups, 1 s apart, after `NotifyOnNewObject` reports the class loading or the pawn changes. The dragon lookup used to poll every 60 frames.
